Проект - Читалка Илиады/Iliad Reader

Рус:
Суть проекта: Электронная книжка читалка Илиады Гомера
с аннотациями которые появляются при нажатии
выделенного текста, сделанный языке программирования
Python, Html, JavaScript, Sqlite3 и Фреймворк
Django. Также, имеет тесты для проверки знаний человека 
и перевод песни и аннотаций на казахский и 
английский. Все аннотации берутся из научных источников,
и для русской, и для английских аннотаций.
Все источники хранятся в Russian_Reference.
Сайт доступен на: https://iliad-reader-8stg.onrender.com

Eng:
Overview: An electronic reader/book of the Iliad
by Homer, with annotations that pop up whenever
you press on the highlighted text for historical/
etymological/cultural context. Created using Python, HTML
JavaScript, Sqlite3, Django framework. 
Also contains a test section to check your knowledge 
and to ensure you actually read the annotations.
All of the annotations were hand written by me
and come from legitimate scientific sources
such as articles, databases and literary works.
The bibliography is in the English_Reference text file.
Site available at: https://iliad-reader-8stg.onrender.com
